# Current voice edition — 20 September 2026

The playable HTML uses human-recorded short reactions, greetings and non-verbal performances. It does not load or export the older local text-to-speech dialogue archive. The unused legacy files remain in the editable source folder for history.

Specific story dialogue without an actor recording is shown in subtitles. This is not a complete human-voiced cast. Audio quality was checked for decoding, duration and clipping with computer output muted; the new recordings were not auditioned aloud during testing.

Ten selected WAV clips are in `assets/audio/human`. Source filenames, source SHA-256 hashes, durations, actor names and source URLs are recorded in `assets/audio/human/manifest.json`. Converted to mono PCM and levelled below 0.63 peak; no voice cloning or new synthesis. Archives were used only to extract audio files. No software was installed.

Existing non-verbal recordings retain the per-file provenance in AUDIO_ASSET_MANIFEST.md.
